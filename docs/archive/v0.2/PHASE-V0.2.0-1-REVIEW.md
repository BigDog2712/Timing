## 四、关键架构结论（设计师 4 问已裁定）

| 问题 | 裁定 |
|------|------|
| 多窗口模型 | 四类窗口统一目录 + 四条一致机制（label 路由 / 几何持久化+多屏钳制 / 防白闪三件套 / 主题广播各窗自订阅）。ADR-009 |
| **托盘菜单自绘** | **核实：Tauri v2 托盘菜单 = 原生 Win32 `HMENU`+`TrackPopupMenu`，无法自绘**。方案 B（禁原生菜单 + 光标处弹透明置顶 WebviewWindow），成本 **~2-3 人日**；回退 A 保留信息架构 |
| 中文字重 | `Microsoft YaHei UI` 仅 300/400/700 → 中文层级只用 **{400,700}** + 字号/颜色/字距承载；`font-synthesis-weight:none` 禁伪粗体；MVP 不内联字体 |
| 玻璃立场反转 | 核实：`backdrop-filter` 只模糊 webview 内部、不穿透 OS 图层。设计师「高不透明板 + 文字不透明」= **板式拟玻璃，安全**；默认不启用 OS Acrylic；主小条禁挂模糊；**与 K-1 白闪无因果** |
