## 2. 造数据（AC-54「提醒色」/ AC-37「铃铛」验证前置）

> 批1 的 UI 没有录入 `planned_at` / `remind_at` 的入口（属批2），而这正是「提醒色」唯一的两个消费者。要肉眼看到提醒色生效，须先有一条这样的待办。

**方式 A（推荐，界面内）**：暂无入口 —— 只能走方式 B。

**方式 B（直接写库）**：数据库文件为 SQLite（应用标识 `com.tickbar.app`）。可用任意 SQLite 工具打开，插入一条已逾期/带提醒的待办：

```sql
-- 已逾期（planned_at 早于当前）：触发「已逾期」文字用色（--todo-overdue → --color-warn）
UPDATE todos
SET planned_at = strftime('%s','now') - 3600
WHERE id = <你的某条待办 id>;

-- 带提醒（remind_at 非空）：触发「提醒铃」
UPDATE todos
SET remind_at = strftime('%s','now') + 600
WHERE id = <你的某条待办 id>;
```

- 落库后**重开事项窗口**即可看到「已逾期」文字 / 铃铛。
- 此时回设置页改「提醒色」，两处应立即变色。

> 数据文件位置（Windows）：`%APPDATA%\com.tickbar.app\` 下的 `.db` 文件（具体名以实际为准，可用 `%APPDATA%` 搜索 `tickbar`/`com.tickbar.app` 定位）。
