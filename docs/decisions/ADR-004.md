# ADR-004: 锁定 Lucide（lucide-react）作为唯一 SVG 图标库

## Status

Accepted (2026-10-16)

## Background

团队 P0 绝对规则规定：Spec 必须锁定一套 SVG 图标库，禁止 emoji 作为功能图标，且禁止混用多套图标。TickBar 为深色药丸 UI，图标用量小但要求风格统一、可随主题着色、体积可控。候选：Lucide、Heroicons、Phosphor、Radix Icons、React Icons。

## Decision

**锁定 `lucide-react@1.57.0`**（Lucide 图标集，MIT/ISC 许可）为全项目唯一 SVG 图标库。

理由：
1. **纯 SVG 组件，非字体、非 emoji**，满足 P0 规则。
2. **Tree-shakable**：仅打包被 import 的图标（每图标约 1KB），对低占用友好。
3. **统一设计语言**：24×24 viewBox、默认 2px stroke、`currentColor` 描边，天然适配深色主题，可用 `size`/`color`/`strokeWidth` 统一控制。
4. TypeScript 一等支持，peerDeps 兼容 React `^19.0.0`。
5. 生态默认（shadcn/ui 默认图标集），团队迁移与参考成本低。

**强制约束**：全项目只允许 Lucide；禁止 emoji 图标；禁止引入 Heroicons/Phosphor/FontAwesome 等其他图标库。图标清单与用途映射见 ARCHITECTURE §4.2。

## Consequences

正面：
- 风格统一、可主题化、体积可控，符合 P0 与低占用目标。
- 图标即 React 组件，无需字体加载与 CSS class 约定。

负面：
- 需避免全量 `import * as icons`，否则破坏 tree-shaking（必须具名/按需 import）。
- 图标名以 Lucide 为准，设计稿若用其它图标需按 §4.2 映射表转换。
