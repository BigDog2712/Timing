# ADR-031：事项窗编辑 = 就地打字（取代日历浮层选时间）

## Status

Accepted（2026-10-20，V0.3.13）；取代 ADR-028 §「点哪改哪」里的**改时间交互**部分
（ADR-028 的「点哪改哪」原则不变，只是从「点开浮层选」变成「点开就地打」）。

## Background

V0.3.10 把待办行的两个时间做成「点开 `DateTimePicker` 日历浮层选」。V0.3.11 把这条规则
扩到计时行（记录起止时刻）。用户真机试过后否掉了这个交互（原话）：

> 编辑的方式是错误的，应该是直接手打修改的东西即可 比如点开编辑事项后，相当于开了编辑模式
> 点击一个事项名，随后可以删除、写下其他名字，点击某一事项的开始时间，输入新的时间即可。
> 修改完毕后再次点击编辑事项，结束编辑。

要点有三条：**（1）名字是「删改文字」而不是「弹编辑条」；（2）时间是「打字」而不是「选日历」；
（3）编辑模式是一个整体开关（再点一次退出）**。

## Decision

### 1. 名字：原地变文本框

新增 `InlineText`（`components/todos/InlineText.tsx`）：

- 进入即 `focus()` + `select()`（点一下就能整段改写）；
- `Enter` 提交、`Esc` 取消、**失焦也提交**（点别处就走，不用找「确定」）；
- 提交被拒（`onCommit` 返回 `false`：空名字 / 时间句子解析不了）→ **保持编辑态**并标红
  （`data-invalid`），绝不悄悄吞掉用户打的字；
- 键位一律 `stopPropagation`：行上的 Space / Enter / R / Delete 与面板的 Esc 关窗都不能在打字时误触发。

原来那套「整行替换成 `InlineEditBar`（输入框 + 确定 / 取消）」的路径被删除，`InlineEditBar` 组件一并删除。

### 2. 时间：手打 + 轻量解析

新增 `lib/timeInput.ts`：

| 写法 | 含义 |
| --- | --- |
| `09:00`、`9:05` | **今天**该时刻（面板本来就是今天的时间线，不自动翻页） |
| `明天 09:00` / `后天 21:00` / `今天 23:00` | 相对日 |
| `10-21 09:00` / `10/21 09:00` | 当年 |
| `2026-10-21 09:00` | 带年份 |

- 全角数字、全角冒号、`／`、`－` 先归一；
- 解析不了（`下午三点`、`24:00`、`13-01`、`2-31`）→ 返回中文原因，输入框保持编辑态；
- 回填文本 `timeInputText()` 与解析器**往返一致**：今天给 `HH:MM`，同年跨天给 `MM-DD HH:MM`，
  跨年给 `YYYY-MM-DD HH:MM`（少了年份会在跨年时悄悄丢一年，单测抓到的）；
- **空串 = 清空该项**（待办两项时间都可空）；计时记录的时刻不可空；
- 业务校验不变：`lib/todoTimes.ts::todoTimePatch` 仍判「截止不得早于开启」，
  计时行的「结束不得早于开始」由行内先挡一次、后端 `update_record` 再挡一次。

### 3. 编辑模式是整体开关，行内状态归行自己

- 底栏「编辑事项」打开 / 关闭整个模式；事项菜单里的「编辑事项」等价于**打开这个模式**（不再针对单行弹条）。
- 正在改名字 / 正在改时间是**行内状态**（`useState`），面板不再维护 `editingId` 与 `mode='edit'`，
  `RowMode` 从 `view | edit | confirm` 收窄成 `view | confirm`（只剩删除确认条）。
- 编辑模式下行点击**不再开关提醒**（避免一边打字一边改状态）；完成仍由行尾圆圈负责。

### 4. 保留的东西

- 提醒仍然是「点整行开关、黄圈表示有没有提醒」（ADR-030 未变）。
- 删除仍是「待办即时删 + 撤销条 / 计时行走内联确认条」。
- `DateTimePicker` 仍服务**新增待办卡**（`DateTimeField`）：新建时挑时间比手打方便，
  编辑既有值时手打更快 —— 两种入口分工明确，不是重复。

## Consequences

- 删除三个组件：`InlineEditBar`、`TodoTimeChip`、`RecordTimeChip`；新增 `InlineText`、`TimeTextChip`、
  `lib/timeInput.ts`（含 7 条单测）。
- 手打时间**不做「未来 / 过去」的方向推断**：只给 `09:00` 永远是今天 09:00。跨天必须显式写
  `明天` 或 `10-21`，这是有意的（猜错日期的代价远大于多打几个字）。
- 时间输入的宽度固定 62px（`.inline-text--time`）：打字时左右两列不会跳动；实测 252 面板内
  编辑态记录行「名字 76 + 时间位 106 + 删除」正好贴右沿、不溢出、行高仍 26。
- 输入框吃掉所在格子后名字会变窄（待办行编辑时间位时约 58px）—— 瞬时状态，靠省略号兜底。
