# ADR-038：悬浮形态可切换（悬浮条 / 小圆点），小圆点承载「环 + 时间」

## Status

Accepted（2026-11-05，V0.11.0）

## Background

收起态（`CollapsedDot`）从 0.2.0 起一直是**一枚 28px 的空心环**：只有颜色区分状态，没有读数。
用户在 V0.11.0 提出的口径是「移植手机端小圆点功能，复现环 + 分钟显示时间效果并保持一致，
支持在设置中切换悬浮形态为小圆点或悬浮条」。

两个事实推动这个改动：

1. **手机端 `TimerRing` 已经是「环 + 时间」**：232px 正圆、8px 描边、中心 `MM:SS` +
   一行说明，弧语义直接复用 `MainButton.arcSpec`。桌面收起态与它**不是同一个语言**——
   同一个用户在两台设备上看到两个东西。
2. **收起态是唯一不显示时间的状态**：用户把条收起来是为了「不挡视野」，不是为了
   「看不见跑了多久」。28px 的环放不下任何文字，所以要么保持现状，要么把它做大。

同时，`collapsed` 一直由用户手动触发（菜单「收起为圆点」），下次启动又回到悬浮条——
「我更喜欢圆点」这个偏好无处安放。

## Decision

### 1. 新增「常驻形态」偏好，与运行时折叠态分离

| 概念 | 承载 | 语义 |
|---|---|---|
| 常驻形态 `floatForm` | `appearanceStore`（localStorage `timing.appearance.v1`） | `bar`（默认）/ `dot`。**决定启动时的形态** |
| 运行时折叠 `collapsed` | `uiStore` | 当前这一刻显不显示条。点圆点、点菜单都会改它 |

- 启动时（`initAppearance`，渲染前）按 `floatForm` 设一次 `collapsed`，所以**没有
  「先闪一条再变圆点」**。
- 切形态**立即生效**，不重启；只改形态时不写库、不进设置表（纯显示偏好，与不透明度同类）。
- 反向不成立：用户临时点开看一眼条，**不回写 `floatForm`**。否则「我更喜欢圆点」会被
  一次窥视改掉。
- 非法值（手改 localStorage / 老版本没有这个键）一律回落 `bar`——升级用户不会莫名被收起。

### 2. 小圆点改为「环 + 时间」，尺寸 76

| 项 | 手机 `TimerRing` | 桌面 `CollapsedDot` | 说明 |
|---|---|---|---|
| 外径 | 232 | 76 | 桌面是常驻角落的挂件，不能占视野 |
| 描边 | 8 | 3 | 比例 3.4% → 桌面取 2.6 向上归整到 3 |
| 时间字号 | 40 | 15（跨小时 11） | 76px 的圆装不下 8 个字符的 `HH:MM:SS` |
| 弧语义 | `arcSpec` | `arcSpec`（同一个函数） | 桌面与手机不各写一套 |
| 时间口径 | `formatDuration` | `formatDuration` | 都是 `MM:SS` / `HH:MM:SS` |

- 读数口径与 `PillBar` 完全一致：倒计时显示**剩余**、空闲但已定时长显示该时长、否则正计时。
- 倒计时剩 ≤60s 切 `--color-danger` 并 1s 闪烁（与悬浮条同阈值、同节奏）。
- 描边加粗只用于 ended 的 900ms 确认（`arc.thick`），与 `MainButton` 同一条规则。

### 3. 样式迁出 `surfaces.css`

`surfaces.css` 当时 296 行，圆点新增的 60+ 行必破「单文件 ≤300 行」（ADR-017）。
新建 `src/styles/dot.css`，并把 `--hit-target-dot`（唯一消费方是本文件）删掉。

## Consequences

**好处**

- 三处（悬浮条环、桌面圆点、手机大环）用同一套弧语义，改一处不会只改到一处。
- 收起后仍能看到读数，收起变成「换个形态」而不是「放弃信息」。
- 形态偏好持久化，重启保持。

**代价**

- 圆点从 28px 涨到 76px：常驻面积约为原来的 7.4 倍。放在屏幕角落仍然很小，
  但**不再是「一个点」**，所以设置项名字必须写「小圆点」而不是「圆点」——
  用户点开设置看到的形态要和实际一致。
- 主窗会因内容变大而重新 auto-fit（窗口收缩到内容包围盒，ADR-014），
  切换形态时窗口会有一次尺寸跳变。这是既有机制，不是新问题。
- 76px 的圆在 125% / 150% DPI 下不会对齐到整数物理像素，圆环会有轻微模糊。
  可接受（描边 3px 已留了余量），未做 DPI 取整。
