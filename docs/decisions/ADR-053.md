# ADR-053：托盘「Markdown 同步」的四个判断

## Status

Accepted（2026-11-06，V0.11.7；用户口径「在桌面栏右键开发一个功能，MD 双向同步。点一下就可以完成同步」）

## Background

同步本体 `services::md_sync::run` 早就存在，设置页也有「立即同步」。缺的只是**不打开任何窗口就能触发**
的入口。托盘是唯一常驻的交互面，所以加一项菜单。

难点不在「调哪个函数」，而在「点了之后用户看到什么」。同步有三种非成功状态，任何一种静默都等于
回到「点了没反应」：

| 状态 | 现状 |
|---|---|
| 未启用（出厂默认就是关） | `sync_all` 在 `!config.enabled` 时**静默返回空报告** |
| 单落点失败 | `run` 只在整体不可执行时返 `Err`；单点失败落在 `report.errors` 里，`Ok` 照常返回 |
| 无变更 | 报告全零，与「根本没执行」在界面上无法区分 |

## Decision

### 1. 未启用必须在调用前判，不能靠 `run` 自己

`md_sync::config::load(pool)`（设置页与轮询同源），`enabled == false` 直接通知
「先在设置里打开 Markdown 同步」并返回。理由：`sync_all` 的静默分支是为轮询任务设计的（轮询时不该刷屏），
直接复用就把静默带到了用户主动点击的路径上。

### 2. `report.errors` 非空按失败告知

部分成功报「完成」是撒谎。`errors` 非空 → 标题「Markdown 同步失败」，正文 `errors.join("；")`，
同时 `log_warn`。用户至少知道「有一档没写进去」。

### 3. `exported` 是**落点数**，不是文件数

`MdSyncReport.exported` 统计的是写了几处（`MdSyncBinding::key()` 含 heading，两个落点可以指向同一个
文件的不同标题）。文案写「导出 M 处」，不写「M 个文件」。

### 4. 防重入用 RAII，不用裸 store

```rust
struct Gate;
impl Drop for Gate {
    fn drop(&mut self) { RUNNING.store(false, Ordering::SeqCst); }
}
```

原写法把 `store(false)` 放在 `await` 之后：`?` 早退或 panic 时永不执行。RAII 把复位挂到 `Drop` 上，
正常返回 / `?` 早退 / unwind 三条路径都能复位（本 crate 未设 `panic = "abort"`）。

**它不解决「挂住」。** future 停在 `await` 上时既没结束也没被 drop，`Gate` 还活着，闸仍是 `true`。
而挂住恰恰是最现实的一种：同步落点常配在 OneDrive / 网络盘（正是产品推荐的位置），IO 卡死时这一轮
永不返回，此后点一百次都没反应，只能重启进程。根治要给 `run_once` 套 `tokio::time::timeout`，
但「一轮最长允许多久」「超时算失败还是算跳过」是新决策，本轮不做，记在这里。

命中闸时的反馈：本轮**第一次**被拦的点击弹一条「上一次同步还在进行中」，「本轮弹过没」用一个
`AtomicBool` 记，一轮开始时复位。比时间戳节流更可预测：不依赖时钟，也不会因为机器卡顿多弹。

## Consequences

- 每次点击都要多读一次配置与一次 `AtomicBool`，可忽略。
- **故障残留**：真挂住时 `BUSY_NOTICE_SHOWN` 已置位、且只有新一轮开始才清，所以用户会看到**一条**
  「上一次同步还在进行中」，之后连点又回静默。这个残留刻意留着——挂死本身只能重启恢复，
  在闸上做花样没有意义，要修就修超时。
- 通知是这几条分支的**唯一出口**：被专注助手 / 通知权限拦掉时用户什么都看不到。所以 `notify()` 的
  返回值必须检查并落 `log_warn`（`tray md sync notify suppressed: <title>`），否则连排查线索都没有。
- 托盘没有「同步中」的进度反馈。一轮通常 <1s；慢速网络盘上可能几秒。要「点了立刻有反应」得在菜单项
  文案上做文章，但整菜单重建受 K-30（只在状态迁移时重建）约束，需要单独议。
- `app/tray.rs` 加完这些到 313 行，撞 300 门禁。按 ADR-017 拆出 `app/tray_sync.rs`，**没有开豁免**。
