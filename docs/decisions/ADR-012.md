# ADR-012: 双主题采用 HTML 属性 + 双套 CSS 变量，前端主导、避免首屏白闪

## Status

Proposed (2026-10-16) — 待 V0.2.0-1 用户确认后转 Accepted

## Background

V0.2.0 新增「深浅双主题」（可切换）与「四色可配」（计时中 / 提醒 / 完成 / 小条底色）。任务要求：前端 `ThemeProvider`、持久化、**首屏无闪烁**。V0.1.0 为恒定深色单主题（令牌见 `docs/design/design-tokens.css`），且规定「组件 CSS 零裸 hex」。

候选实现：

- **A**：`<html data-theme="dark|light">` + 两套同变量名 CSS 变量 + `<head>` 内联引导脚本。
- **B**：React state 挂 class，按主题条件渲染两套样式 / 内联样式。
- **C**：运行时 `style.setProperty` 逐变量覆盖。

约束：多窗口（主窗 / 设置窗 / 事项窗 / 便利贴窗）须主题一致；首屏不得白闪；零裸 hex 纪律；浅色主题下对比度须仍满足 AA。

## Decision

**采用方案 A：令牌按 `data-theme` 属性切换；四色由运行时 CSS 变量注入；首屏由 `index.html` 内联脚本同步设定，窗口 `visible:false` 首帧后 `show()`；`theme.mode` 存 settings（事实来源）+ `localStorage` 快取。**

具体锁定项：

1. **令牌承载**：`:root`（或 `:root[data-theme="dark"]`）为深色，`:root[data-theme="light"]` 为浅色；两套**同变量名、不同值**。组件 CSS 只引用 `var(--*)`，零裸 hex（沿用 V0.1.0 纪律；唯一例外 `--elev-*` 阴影组 + 注入变量）。
2. **ThemeProvider**（`components/theme/ThemeProvider.tsx` + `lib/theme.ts`）：解析 `themeMode='dark'|'light'|'system'`（`system` 读 `matchMedia('(prefers-color-scheme: light)')` 并订阅）；应用 `document.documentElement.dataset.theme = resolved`。
3. **四色注入**：`lib/theme.ts` 把 `accents.{running,warn,done,bar}` 注入运行时变量（`--color-running` / `--color-warn` / `--color-done` / `--color-bar`）；默认不设 = 用令牌值，用户显式设置才覆盖。**变量名已与设计师对齐（见下）**。
4. **持久化**：`settings.theme.mode` 为事实来源；同时写 `localStorage['tickbar.theme']` 作为首屏快取。
5. **首屏无白闪（K-18）**：① `index.html` `<head>` 内联同步脚本读 `localStorage['tickbar.theme']`（缺省 `'dark'`）并立即设 `data-theme` + `color-scheme`；② 新窗口 `visible:false`，前端首帧渲染完成后再 `show()`；③ 令牌 `:root` 提供兜底 `--bg`，保证「只设了 data-theme、CSS 未解析」也非纯白。
6. **浅色对比度（K-17）**：`lib/theme.ts` 提供 `deepenForNonText(hex, bg, 3.0)`（保色相、0.05 步进加深至 ≥3:1）供非文本使用；作文字用 ≥4.5:1 的 `--color-*-ink` 派生。两套主题逐对 AA 纳入验收。
7. **多窗同步**：`theme_set`/`accent_set` 触发 emit `theme-changed`（**广播所有窗口**，K-21），各窗 ThemeProvider 重设 `data-theme`。
8. **令牌值定稿归设计师**：具体双套令牌数值由 `UIUX-V0.2.0` / `design-tokens V0.2.0` 产出；机制契约（属性名、四色变量名、派生规则、兜底背景）由本 ADR / 架构文档锁定，双方对齐。

## Consequences

正面：
- 零新增依赖；主题切换瞬时、无重渲染开销；多窗天然一致。
- 内联脚本 + 隐藏首屏 + 兜底背景三重保证首屏无白闪。
- 四色以 CSS 变量注入，用户配置与令牌解耦，组件不感知来源。

负面 / 需处理：
- 需维护两套令牌值，浅色主题须逐项核对比度（K-17）。
- 新增窗口都要复制「内联脚本 + `visible:false` + 兜底背景」三件套（模板化到窗口基座可缓解）。
- `theme-changed` 广播到所有窗口，便利贴等窗口需按需响应（K-21）。
