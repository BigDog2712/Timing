## 3. 状态与交互

### 3.1 触发形态（对齐 PRD §2.11 / AC-61）

| 形态 | 说明 |
|---|---|
| **系统通知（必须）** | Rust 侧 `tauri-plugin-notification` 发一条 Windows 通知。**单条**：标题=事项名，正文=时间；**聚合**：标题=「3 条事项到点」，正文=A、B、C 等。点击通知 → **打开事项窗口**（聚合）/ 聚焦并弹本卡（单条）。 |
| **应用内视觉提示（必须）** | 事项窗口对应行**短暂高亮**（`--accent-wash` 底 + `--dur-confirm` 900ms）。**提醒不占用药丸条常驻宽度**——不把小条撑长。 |
| **应用内浮出卡** | 单条提醒时，弹窗贴近小条浮出（不抢焦点，`--dur-base` 200ms 淡入 + 上移 8px）。 |

> **边界（务必遵守）**：**提醒 ≠ 结束计时**。提醒只做「告知」，**不做「自动结束计时」**——「到点自动结束并保存」归**倒计时**（`countdown-menu.md` / AC-62）。两者语义不混淆。

### 3.2 交互态

| 状态 | 弹窗 | 主按钮 | 稍后 |
|---|---|---|---|
| Default | 玻璃底 + `--line-2` + `--shadow-pop` | `accent`（`--accent-wash` 底 / `--accent-ink` 字） | `ghost`（`--ink-3` 字） |
| Hover | 无变化（弹窗本体非交互） | 底加深 | 字 → `--ink` |
| Active | — | `scale(0.98)` | 同左 |
| Focus-visible | `--focus-ring` 双环 | 同左 | 同左 |
| Auto-dismiss | **不自动消失**（提醒须被看到），但系统通知 8s 后自动收起；应用内卡常驻至用户操作或 30s | | |
| Loading | — | 「开始新计时」点击后变 spinner 一帧 | — |
| Empty | 不适用（提醒必有内容） | | |
| Error | 副文位显示「提醒时间无效，已清除」（`--danger`）+ `ghost`「关闭」 | | |
| Edge | 事项已删除 → 副文「该事项已不存在」+ 仅「关闭」；提醒时间已过期（休眠导致）→ 走 §3.5 补发 | | |

### 3.3 「稍后提醒」选项

`5 分钟` / `15 分钟` / `1 小时` / `明天此时` —— 写入新的 `remind_at`，走 `reminder_set`。

### 3.4 聚合通知（AC-61）

- **窗口**：同一时间窗 **±60s**（`size.reminderMergeWindowMs` = 60000）内到点的多条 → **必须合并为一条聚合通知**。
- **文案**：标题「`N` 条事项到点」，正文「A、B、C 等」（超出 3 条折叠为「… 等」）。
- **点击**：打开**事项窗口**（不是逐条弹卡）。
- **应用内**：不弹 N 张卡；仅事项窗口对应 N 行各自短暂高亮。

### 3.5 休眠唤醒补偿（AC-61）

```
唤醒后 —— 错过的提醒合并补发一条：
+--------------------------------------------+
| [bell] 有 2 条提醒已过期                     |  ← 标题 13/600
| 10:10 摸会儿鱼 · 09:30 剪头发                |  ← 副文 11.5/--ink-3
| [ 打开事项窗口 accent ]  [ 全部清除 ghost ]   |
+--------------------------------------------+
```

- **合并补发一条**（形如「有 N 条提醒已过期」），**不逐条弹**。
- 事项窗口对应行标**逾期警示色**（`--todo-overdue` = `--warn`）。
- **逐条可清除**；**不弹阻塞框**。

### 3.6 键盘路径

`Enter` 触发主动作；`Esc` = 关闭（记录「未处理」）；`Tab` 在按钮间移动；`S` 快捷「稍后」。

## 6. 本页 Override 差异（相对 MASTER）

| 字段 | MASTER 默认 | 本页覆盖 | 原因 |
|---|---|---|---|
| 自动消失 | 通用 toast 自动淡出 | **不自动消失** | 提醒必须被看到 |
| 强调色用量 | ≤2 处 | **≤1 处**（accent 主按钮） | 弹窗面积小，克制 |
| 位置 | 居中 dialog | 贴近小条浮出 | 与产品形态一致（非模态对话框） |
