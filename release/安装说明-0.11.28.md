# Timing 桌面 0.11.28 · 安装与自测

> **一句话**：设置页说话方式大清理（标题带 WebDAV、解释照你原话），自动同步钉死三档，
> 新增日记模板。悬浮小圆点的竖条改动在这版**代码里已就绪**，但要等安卓轮出手机包才能看到。

---

## 一、怎么装

| 项 | 值 |
|---|---|
| 安装包 | `Timing-0.11.28-setup.exe`（约 5.0 MB） |
| 便携版 | `Timing-0.11.28-portable.zip`（解压即用，数据在 exe 同级 `data\`） |
| SHA256 | 见 `SHA256SUMS-0.11.28.txt` |

覆盖安装即可，老数据自动迁移（只复制不移动，原目录不动）。

## 二、这版有什么

1. **设置页标题**：本地同步 → 「WebDAV本地同步」；云端同步 → 「WebDAV云端同步」。
   解释照你的原话逐字改；Markdown 同步解释改为「数据汇总至 md 文档，便于 ai 汇总读写」。
2. **自动同步三档**：关闭（不自动）/ 自动（间隔分钟自己设）/ 智能（启动后 1 分钟一轮、
   停手 5 分钟一轮、30 分钟兜底一轮）。手机端同位置的「定时」也改成了「自动」。
3. **日记模板**：设置 → Markdown 同步里新增「日记模板路径」。填上模板文件路径
   （如 Obsidian 的日记模板），同步**首次写出**某天的日记文件时就用模板打底；
   文件已存在不套；路径填错只是不套模板，同步照常。

## 三、自测清单（三分钟）

1. 打开设置：两个新标题 + 三句新解释逐字对。
2. 云端同步自动同步：切 关闭/自动/智能 三档，自动档改间隔分钟数，保存后重开设置还在。
3. 日记模板：配一个模板路径 → 计时一次 → 去 md 目录看当天日记是否以模板内容开头；
   再计一次（文件已存在）→ 确认没被模板覆盖。
4. 老数据还在：开始计时 → 暂停 → 结束 → 记录里能看到。
