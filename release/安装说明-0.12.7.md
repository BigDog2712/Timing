# Timing 桌面 0.12.7 · 安装与自测

> **一句话**：主界面这套排布定稿成默认布局；编辑事项收成一张弹层（改起止只改时刻）；
> 热力图重做成整月 × 6 个四小时段；药丸快捷新建能带标签和应用；卡里能用滚轮看全数据。
> 上一版桌面出包是 0.12.6。

---

## 一、怎么装

| 项 | 值 |
|---|---|
| 安装包 | `Timing-0.12.7-setup.exe`（约 8 MB，NSIS） |
| 便携版 | `Timing-0.12.7-portable.zip`（解压即用，数据在 exe 同级 `data\`） |
| SHA256 | 见 `SHA256SUMS-0.12.7.txt` |
| 构建身份 | `BUILD-INFO-0.12.7.txt`（提交号与工作树状态，与包一一对应） |

覆盖安装即可。老数据自动迁移（只复制不移动，原目录不动）；**已有布局不会被改写**——
新默认布局只对新装、清空布局、坏存档回落和「出厂布局」生效。

## 二、这版有什么

### 1. 主界面：当前排布成为起始布局

左列计时分布 / 今日时间线，中列应用排行 / 事项管理，右列热力图 / 活动趋势 / 便利贴，
底部活动提醒。卡内滚轮能把数据看全（计时分布图例不再截 4 条、应用排行不再砍 5 条）；
便利贴最小可缩到 200×96，纸片区自己滚。

### 2. 今日时间线：上区记录、下区待办

上方看今天做了什么（进行中含走钟，暂停写明「已暂停」），下方看还要做什么；
卡头有「新建事项 / 编辑事项」。历史事项组已下线，去「事项管理」找。

### 3. 编辑事项一套口径

新建 / 编辑事项都能设正 / 倒计时、默认时长、标签（带 AI 建议）、绑定应用；
新建不再选分类，分类只在事项管理里改。事项管理卡点行 = 编辑，行尾圆点 = 起停
（灰空闲 / 蓝计时 / 黄待办），切换在计时的事项会先确认。

### 4. 改起止只改时刻

时间线行上不再有悬停按钮。点「编辑事项」→ 底部「今日记录」→ 每段旁边「改起止」。
输入的是 09:00 这样的时刻，日期不出现；进行中的段改不了，结束早于开始会就地提示。

### 5. 药丸快捷新建

空闲时在条上输入名称，可顺手加标签（AI 按名称建议）、点选最近 8 个前台应用，
再开始。附加项失败不会把已建的事项丢掉。

### 6. 热力图重做

横轴整月日期（每 5 天标一次，可横向滚），纵轴第一行是当日合计，下面 6 个四小时段
（0 / 4 / 8 / 12 / 16 / 20）。卡头可往前翻月；今天没开始的时段画虚线。

### 7. 标签

应用排行 / 应用趋势里新打的标签，当场出现在数据页「标签管理」（保存时补定义行）。
标签新建回车后焦点留在输入框；拖动改分类在 Windows 上恢复。

## 三、自测清单（五分钟）

1. 主界面是 8 张卡：左列计时分布 / 今日时间线，中列应用排行 / 事项管理，右列热力图 /
   活动趋势 / 便利贴，底部活动提醒。
2. 计时分布右侧图例超过 4 条也全都在；鼠标停在卡里能往下滚。
3. 便利贴拖到最小（约 200×96）不弹回，纸片区可滚。
4. 时间线卡：上区有今天的记录，下区有待办；进行中的行在走秒，暂停行写「已暂停」。
5. 点「编辑事项」→ 选一条有记录的，底部「今日记录」里改一段的开始 / 结束时刻 →
   时间线当场更新；填 23:30–01:00 会提示结束要晚于开始。
6. 事项管理卡点一行 → 打开编辑；行尾圆点：空闲灰、正在计蓝、有待办的黄。
7. 热力图：第一行是「day」合计，日期 1、5、10…标注，切上个月数据跟着换。
8. 数据页 → 标签管理：给某个应用新打一个标签，回来能在这个列表里看到；
   再输入标签名按回车，焦点还在输入框，可以接着敲下一个。

## 四、升级须知

- 计时记录、便利贴、待办、标签、绑定关系都原样保留；旧布局原样保留。
- 布局管理里的「出厂布局」现在会给出这一版排布；自己存过的默认布局不受影响。
- 安装包未做代码签名，SmartScreen 可能提示"未知发布者"；可用便携版，或对照
  `SHA256SUMS-0.12.7.txt` 后运行。
