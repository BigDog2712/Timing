# Timing 0.11.24 安装说明（桌面双形态）

这一版做一件：**异常退出后的恢复框重做**。上次软件没正常关（强杀 / 断电），重启后弹的框
从「两个模糊按钮 + 一个复选框」改成「两条都带具体时间的路」：

- **一直算到现在（13:40:12）**——关机那段也算工时；
- **结束在 18:40（04:12:30）**——计到关机那一刻为止（不是「现在」）。

Esc = 按关闭时间结束（原来是继续计时）。暂停中崩溃只出一个`结束并保存（…）`。
托盘「退出」时若有没结束的计时，先按关闭时间收尾、再做最后一轮同步。
契约 79 命令 / 17 错误码 / 11 事件 / 迁移 `0006` 没动，手机端零改动（仍用 0.11.23 的 apk）。

产物（都在 `D:\101-Workshop\261108-Timing\release\`）：

## 桌面怎么装

1. **便携**：解压 `Timing-0.11.24-portable.zip`，把 `Timing.exe` 覆盖到你现在的 Timing 目录
   （比如 `C:\Software\SmallTools\Timing\`）。**只覆盖 exe**——`data\` 别动，你的数据都在里面。
2. **安装包**：双击 `Timing-0.11.24-setup.exe`。注意它装到 `%LOCALAPPDATA%\Programs\Timing\`，
   与便携目录是两个数据根；想沿用老数据要手工搬 `data\`。
3. 校验（可选）：`certutil -hashfile Timing-0.11.24-portable.zip SHA256`，对照 `SHA256SUMS-0.11.24.txt`。

## 装完怎么试这一版（杀进程不用心疼，就是给它设计的）

| # | 怎么做 | 该看到什么 |
|---|---|---|
| 1 | 开始计时 → 任务管理器结束 Timing 进程 → 等一分钟 → 重开 | 弹出「上次计时没有正常结束」；元信息一行里有开始与关闭两个时刻 |
| 2 | 点「一直算到现在（…）」 | 计时继续，累计含关机那段；库里这条没有结束时刻 |
| 3 | 重复 1，这次点「结束在 HH:MM（…）」 | 记录结束在**关闭那一刻**的时长，不是重开时刻 |
| 4 | 重复 1，这次按 Esc | 等于点「结束在 …」（少算好补，多算难拆） |
| 5 | 暂停 → 杀进程 → 重开 | 只有一个按钮`结束并保存（…）`，元信息`09:12 开始，已暂停` |
| 6 | 托盘右键「退出」（有计时在跑时） | 计时先按关闭时间收尾保存，然后才跑退出前那轮同步 |

## 这一版明确没做的

- 不做心跳、不做「杀进程也抢救一次」：被强杀就是 ≤30 秒的落盘误差，用关闭时间兜住；
- 不动手机端（零 diff）、不加命令、不加迁移；
- 恢复框不超时、不自动选——数据的事必须你拍板。
