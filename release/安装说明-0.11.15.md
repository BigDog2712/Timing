|---|---|---|

| `Timing-0.11.15-setup.exe` | 4.7 MB | NSIS 安装包（装到 `%LOCALAPPDATA%\Programs\Timing`） |
| `Timing-android-0.11.15-release-arm64-debugsigned.apk` | 10.5 MB | 手机端，调试证书签名，可直接装（arm64） |

- exe 的 sha256：`8d9b3584390662aef1514234f4536f843a39b99292b90745bc07965cf4ee8225`

位置**，那是你自己按的、有确认框、且旧目录不删。

## 方案 A（推荐）：便携覆盖，数据不动

现有安装在 `C:\Software\SmallTools\Timing\`，用的是便携形态（数据在 `<exe>\data`）。

1. **先退出 Timing**（任务栏图标 → 退出，不要只关窗口；它常驻托盘）。
2. 解压 `Timing-0.11.15-portable.zip`。
3. 把解压出来的 `Timing.exe` **单独**复制到 `C:\Software\SmallTools\Timing\`，覆盖同名文件。
4. `data\` 与 `plugins\` **不要碰** —— zip 里这两个目录只是占位 README，覆盖它们没意义。
5. 启动。

覆盖后版本号可在「设置 → 关于」里看到 `0.11.15`。

## 方案 B：用 NSIS 安装包

⚠️ **不要**直接装到现有便携安装上。安装包装到 `%LOCALAPPDATA%\Programs\Timing\`，那里可写，
启动时会被判成便携形态，于是**数据根变成新装目录下的空 `data\`**，看起来就像「数据全没了」
（其实还在旧目录里）。要沿用旧数据，装完把旧 `data\` 整个搬到新目录，或者干脆用方案 A。

## 手机端（可选，这一版只改了页签名字）

`Timing-android-0.11.15-release-arm64-debugsigned.apk` 拷到手机直接装（arm64，Android 8+）。
版本号在手机上「设置 → 关于」看得到 `0.11.15`（`versionCode=11015`）。

- 覆盖安装即可，**不用先卸载**（签名还是同一个调试证书）。数据在应用沙箱里，覆盖不动它。
- 这一版手机端唯一的变化是页签名字 `同步` → `数据管理`，里面一处没动。所以不装也不影响你用电脑端。

## 这一版你能看到的变化

1. **WebDAV 不再刷 409**：远端目录不存在时程序自己逐级建（最多 8 级），建不出来才报错，而且报的
   是一句能照做的话（带出你填的那个路径，不再有裸状态码）。
2. **「测试连接」绿字等于真的能写**：现在它会顺带确认远端目录就绪，绿字里会写「已就绪」或
   「已补建 n 级」。
3. **设置里的「同步」页签改名叫「数据管理」**，页内从上到下五块：Markdown 落点设置 / SQLite 落点
   设置 / Markdown 同步 / WebDAV 云端同步 / 备份数据管理。保存按钮只有一个，在最下面那一条。
4. **数据库（和日志、备份、Markdown 出厂落点）可以换盘**：设置 → 数据管理 → SQLite 落点设置 →
   更改位置。先预检、再让你确认五项与总体积、复制完核对行数、才切指针；重启后生效，旧目录不删。
5. **备份能打开看**：备份数据管理里每行多了「打开」，用系统默认程序打开那份 `.md`。

## 装完建议先验三件（都在设置 → 数据管理）

1. 第四块「WebDAV 云端同步」点「测试连接」→ 应是绿字且带「已就绪 / 已补建 n 级」。
2. 点最下面「保存并同步」→ 状态行应变成 `今天已上传`，没有任何红字。
3. 第二块确认路径还是 `C:\Software\SmallTools\Timing\data`，徽标是「可写」。
