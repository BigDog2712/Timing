# Timing 0.11.25 安装说明

这一版修一个真故障：**手机上点「设置 → 测试连接」，App 会当场消失。**

原因是底下验证 HTTPS 证书那一步在手机上直接崩了（`panic = "abort"`，进程被杀，连日志都写不出来）。
桌面同样的代码是好的——所以从手机端开始做云同步（0.11.21）起，这个洞一直藏到你在真机上点下去。

修法：根证书从「系统里那一份」换成「程序内置的一份」。公网证书（坚果云 / 群晖 / Let's Encrypt）
全部照常；**公司内网自签证书这版不认**（会出红字「证书校验失败」，不再闪退）。

## 手机（Android，arm64）

`Timing-android-0.11.25-release-arm64-debugsigned.apk`（11.1 MB）

- 与本机之前几个包**同一张调试证书**（0.11.15 / 21 / 22 / 23 那几张的同一条），
  **覆盖安装不用先卸载**；
- 装完进「设置 → 数据管理 → 云端通道」，点「测试连接」。

### 自测六步（做完这六步，这个故障就算真的关掉了）

| # | 做什么 | 该看到 |
|---|---|---|
| 1 | 填好地址 / 账号 / 应用密码，点「测试连接」 | 三关逐步点亮，最后绿字「账号、目录、写入都通过」；**App 不能消失** |
| 2 | 故意把密码改错一位，再点 | 红字停在「账号」那一关，后面两关不出现；App 不消失 |
| 3 | 改回正确密码，点「保存」 | 开关变开，状态行说配置已保存 |
| 4 | 点「立即同步」 | 出一份同步结果（导出/导入条数），不闪退 |
| 5 | 在电脑上看坚果云里今天的 `yyyy-mm-dd.md` | 内容与手机上今天的一致 |
| 6 | 手机放后台等 5 分钟（智能档） | 回来再看，没有崩过（下拉通知栏里 Timing 还在） |

哪一步不对，把屏幕上那句话发我——现在出错会给原话，不会只剩一个闪退。

## 电脑（Windows 双形态）

| 文件 | 体积 | 用途 |
|---|---|---|
| `Timing-0.11.25-portable.zip` | 3.7 MB | **推荐**。解压后只覆盖 `Timing.exe`，数据原地不动 |
| `Timing-0.11.25-setup.exe` | 4.8 MB | NSIS 安装包（装到 `%LOCALAPPDATA%\Programs\Timing`） |
| `SHA256SUMS-0.11.25.txt` | — | 三个产物的校验和 |
| `BUILD-INFO-0.11.25.txt` | — | 这份包是哪个 commit、什么时间编的 |

桌面本来不会闪退（Windows 不需要那个初始化动作），但换的是两端共用的网络层，
不跟着换会留两套行为，所以这版桌面包也重出了。

## 仍然不做

- 「导入自签 CA」——这版只在程序里内置了一份公网根证书。要做是另一条路，见 `待决事项`。
- 应用商店上架 / 正式签名：手机包仍是调试证书，自用够；给别人装需要换正式证书（要先卸载）。
