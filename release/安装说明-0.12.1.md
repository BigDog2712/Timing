## 二、这版有什么（挑主人点过名的）

1. **主界面卡片墙**：每张卡可拖位置、拖大小，拖走自动补空；卡头收成一颗 ⋯ 菜单。
2. **今日趋势**：从「近 14 天」改成「今天几点在忙」，峰值时刻写在卡头上。
3. **时间线**：卡底「＋ 新建事项 / 事项管理」。新建可设默认时长、勾「设为常用」（默认不勾）；
   事项管理 = 常用组（上移/下移/取消常用/就地改名改时长）+ 近期组。时长与悬浮条共用同一份。
4. **应用排行**：双击应用 → 改分类 / 绑定事项；分类可建可删（删除后成员回落，颜色别名保留）。
5. **新建待办**：弹层填名称 + 计划时间 + 勾「提醒」。勾了提醒 = 到点前 15 分钟轻提醒、
   前 5 分钟问要不要自动开始；行上小铃铛。勾提醒但时间已过会被拦；只填时间不勾 = 带截止的普通待办。
   注意：**跨零点会清理「计划时间在今天之前」且未完成的待办**（既有行为）——补记只保当天。
6. **便利贴**：留白收紧；点开可删（先问一句）。

## 三、自测清单（五分钟）

1. 主界面拖两张卡换位置、拉一次大小 → 布局记住，重启还在。
2. 时间线卡「＋ 新建事项」→ 填名 + 设 25 分钟 + 勾「设为常用」→ 管理弹层里它排在常用组；
   「↑↓」换位后去悬浮条左键点该事项 → 按 25 分钟起倒计时（同一条设置两处一致）。
3. 待办卡「＋ 新建待办」→ 填名、选 2 分钟后的时间、勾提醒 → 保存：行上有铃铛 + 时间胶囊；
   再建一条只填过去时间不勾提醒 → 能保存且时间胶囊变红。
4. 给某事项设时长后连点两次保存不同事项的时长 → 两条都在（串行队列防覆盖）。
5. 老数据还在：升级前的一条计时记录、一张便利贴、一条待办都应原样出现。

## 四、已知边界

- 待办提醒的两档（T-15 / T-5）是宿主固定行为，本版没有「提前几分钟」选项。
- 分析窗不能改已建待办的时间/名称（无 `todo_update` 授权）——想改去悬浮条事项窗。
- 手机端本版不动：版号 0.12.0 / 12000 仍赋号未出包，出包权归安卓轮。
