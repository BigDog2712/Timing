# Timing 0.11.21 安装说明（只有手机包）

这一版**只改手机**：手机端第一次能自己配云端（WebDAV 地址 / 账号 / 应用密码 / 自动同步三档）。
桌面端一行代码没改，所以没有新的桌面包，仍用 0.11.20 那两个。

## 手机怎么装

1. 把 apk 拷进手机（数据线 / 网盘都行），点开安装；系统提示「未知来源」就允许一次。
2. **覆盖安装即可**：证书与 0.11.15 那个包是同一个（本机 debug.keystore），不用先卸载。
3. 装完打开 → 设置 → 数据管理，应该看到新的三块：**同步通道 / 自动同步 / 云端（四个输入框）**。

## 三条它现在还不会做的（不是坏）

- **手机不删云端往期文件**：桌面会「只留当天」，手机只写不删。删除不可撤销，交给电脑。
- **手机没有备份查看与恢复**：要恢复备份请在电脑上做（备份存在电脑的应用数据目录里）。
- **手机不支持「本地目录」那种云端方式**：那条路要靠电脑上的网盘客户端同步一个真实目录。
