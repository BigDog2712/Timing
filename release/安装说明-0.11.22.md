# Timing 0.11.22 安装说明（只有手机包）

这一版**还是只改手机**，三件事：

1. 本地「日记目录」那条同步路**下线**——手机端只同步云端；
2. 数据管理里**能恢复备份**了（以前只有电脑上能）；
3. 悬浮窗**能开始 / 暂停 / 继续计时**，并且不会再「主界面在计时、悬浮窗不动」。

桌面端一行代码没改，所以没有新的桌面包，仍用 0.11.20 那两个。

## 手机怎么装

1. 把 apk 拷进手机（数据线 / 网盘都行），点开安装；系统提示「未知来源」就允许一次。
2. **覆盖安装即可**：证书与 0.11.15 / 0.11.21 是同一个（本机 `debug.keystore`），不用先卸载。
3. 装完打开 → 设置 → 数据管理，应该看到：**云端同步（开关 + 三档 + 四个输入框）/ 立即同步 /
   备份与恢复**。**看不到**「日记目录」「选择目录」「只用本地 · 本地 + 云端」。

## 这一版改掉的三件（以及一件仍不做）

- **改掉**：本地日记目录同步（要你在手机上指定一个真实文件夹，那条路走不通）；
- **改掉**：悬浮窗只读（以前点它只会回主界面）；
- **改掉**：备份与恢复「请在电脑上操作」；
- **仍不做**：手机不删云端往期文件（删除不可撤销，交给电脑）。

## 如果你之前只配了「日记目录」

升级后手机不会自己同步了（那条路没了）。去「设置 → 数据管理」，把坚果云的账号与应用密码填上、
点保存即可。数据库还在本机，什么都没丢。
