# Timing 0.11.30 安装说明

这一版修**点了没反应**：倒计时、换事项、事项编辑三处的 **右上角 X 点了不关**，
根因是同一个 —— 关闭按钮把「点击事件」当成了「要关哪种面板」，判断永远不成立。
顺带把五项同类问题一起修了，另加一个计时页的快捷同步按钮。

## 手机（Android，arm64）

`Timing-android-0.11.30-release-arm64-debugsigned.apk`（11.1 MB）

- 与之前几个包**同一张调试证书**，**覆盖安装不用先卸载**；
- 装完不用改任何设置。

### 修了什么

| # | 上一版 | 这一版 |
|---|---|---|
| 1 | 倒计时面板右上角 X 点不动 | 一点就收 |
| 2 | 换事项面板 X 点不动 | 一点就收 |
| 3 | 事项编辑面板 X 点不动 | 一点就收 |
| 4 | 记录编辑、便利贴归属面板 X 也点不动（你没碰到但同样是坏的） | 一起修了 |
| 5 | 事项页点一条记录 = **直接开始计时**，想看编辑得长按 | 点 = 事项编辑；行尾新增「▶ 开始」按钮负责计时，长按同义 |
| 6 | 便利贴删除只有「长按」这个看不见的手势 | 每行右上角有垃圾桶，点了先问一句再删 |
| 7 | 同步要去「设置 → 数据管理」翻三层 | 计时页工具条第三个按钮「同步」 |

### 自测七步

1. 计时页点「倒计时」→ 右上角 X：收起。
2. 点「换事项」→ X：收起。
3. 事项页点一条今日记录：弹**事项菜单**（改名 / 归档 / 删除）。
4. 同一条记录行尾点「▶ 开始」：开始或切换到这一条。
5. 记录页点一条记录 → 编辑面板 → X：收起。
6. 便利贴点开一张 → X：收起；行尾垃圾桶 → 出现「删除这张便利贴？」。
7. 计时页点「同步」：提示条给结果；失败时是后端原文。

## 三件还没做（说清楚，别等）

1. **换事项的「近期 / 常用」快捷菜单**（要参考电脑版那块）：需要先把「近期」和「常用」
   的算法定下来（按最近用过 N 条？按次数？置顶算不算），是下一轮第一件。
2. **事项页改成「已完成待办」+ 待办加预计时间 / 提醒 / 选几天后**：待办的三个时间字段
   数据库里**早就有**，缺的是手机端界面和到点提醒的接线。整轮的量。
3. **「本周」没有往期数据**：这条我查不出复现路径（后端的区间过滤与前端算的周一起点都对得上）。
   麻烦告诉我一句现场情况：切到「本周」时**总计有数字吗**、明细空不空、当天是不是周一。
   有这一句就能定位，否则只能盲改。
