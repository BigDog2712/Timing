# 发布说明 · Timing v0.11.1

2026-11-05。上一版对外发布是 v0.5.0（只做改名），本版是 0.11.0 之后的一次修正。

## 这一版改了什么

### 桌面：小圆点变成秒表

收起后的圆点从「76px 环 + 中间时间」改成 **44px 纯图形**：

- 外圈细灰表盘；
- 里面一道圆头进度弧，颜色跟状态（跑=蓝 / 暂停=黄 / 结束=绿 / 倒计时最后一分钟=红）；
- 中心一根指针，正计时 60 秒转一圈，倒计时按已用比例走，暂停就冻住。

圆点里不再显示数字。想看具体时长：鼠标停在圆点上会浮出提示，或切回悬浮条形态。

### 今日事项：同名合成一件事

今天叫同一个名字的事项算同一件事。「写周报」上午写一段、下午写一段，事项菜单里就是两行、
按时间先后排；数据库与 Markdown 里仍是同一条事项、同一个文件，没有拆开。

### 安卓：第一次出包

- 本机装好 JDK 21，Android SDK / NDK 沿用已有安装。
- 产物：`Timing-android-0.11.1-debug-arm64.apk`（183 MB，**debug 签名**，仅 arm64）。

## 安装

### Windows

本轮**没有重新打 Windows 安装包**。开发工作区可 `npm run tauri dev` 直接跑；
要正式分发包需另跑 `npm run tauri build`（本轮未做，NSIS 工具链需要联网）。

### 安卓

```text
adb install -r Timing-android-0.11.1-debug-arm64.apk
```

或者把 apk 拷到手机直接安装（需允许「安装未知来源应用」）。

- 包名 `com.timing.app`，versionCode `11001`，minSdk 24。
- **debug 签名**：只能自己装、自己调试，不能上架、不能给别人长期用。
  正式签名需要 keystore（密码会写进本地配置），等主人点头再生成。
- 体积 183 MB 是因为 debug 版 `.so` 没 strip。要小包得走 release 构建。

## 已知代价

- 圆点的具体时长需要悬停或展开才能看到（这是「环是图形语言」的直接代价）。
- 同名事项合并后，改名只作用于该名字下最早那条；其余同名事项会在下次渲染分裂出来。
- 两条同名待办仍按标题匹配事项，分不开——「名字即身份」的已知边界。

## 回滚

桌面：装回 v0.11.0 或 v0.5.0 即可，数据结构未变。
安卓：`adb uninstall com.timing.app` 后装旧包。
