# 发布说明 · Timing v0.11.7

2026-11-06。桌面端两种形态都在 `release/`：`Timing-0.11.7-portable.zip`（解压即用）与
`Timing-0.11.7-setup.exe`（安装版）。校验和见 `SHA256SUMS-0.11.7.txt`。

## 这一版改了什么

### 1. 托盘右键多了「Markdown 同步」，点一下完成一轮

以前同步要开设置页、找到同步那栏、点「立即同步」。现在右键任务栏图标，「打开事项」下面就是它，
点一下 = 导出（库 → md）+ 导入（md → 库）一轮。

几种反馈都有，不留「点了没反应」：

| 情形 | 你看到 |
|---|---|
| 有变更 | 通知「Markdown 同步完成 / 导入 N 条 · 导出 M 处」 |
| 没变更 | 通知「Markdown 同步 / 没有需要同步的变更」 |
| 没启用同步 | 通知「Markdown 同步 / 先在设置里打开 Markdown 同步」 |
| 上一轮还在跑 | 通知「上一次同步还在进行中，请稍候」（一轮只提示一次） |
| 失败 | 通知「Markdown 同步失败」+ 原因 |

### 2. 快捷新建的事不再显示「未归类」

原因不是名字丢了：事项窗和悬浮条是两个独立窗口，各记一份事项名单。悬浮条新建后只更新自己那份，
事项窗那份停在它上次露面的时刻，翻不到新事项就写「未归类」；而同一件事按名字认，名字一没就退回按编号认，
于是同一事项被拆成好几行。现在事项窗每次重新露面都重读名单；反向也修了（在事项窗改名，悬浮条跟着更新）。

### 3. 新建事项的字号和已有事项名一致

小条空闲态那格「新建事项」原来是 13px 常规，事项名和点进去的输入框是 14px 加粗，点一下会跳档；
现在统一 14px 加粗（颜色仍是提示灰）。事项窗「新增待办」输入框 11.5px → 12.5px，与其生成的行一致。

## 从 v0.11.5 升上来的两件事

### 数据与插件搬到软件旁边（v0.11.6）

`<exe>\data`（库 / 日志 / md 备份）与 `<exe>\plugins`。整个文件夹拷走，记录跟着走。
`%APPDATA%` 的老数据**首次启动自动复制**过来，旧目录原样保留、不删除；搬过一次不再搬。
装在 `C:\Program Files` 这类不可写的位置时，会弹框要你提权或选择改用系统目录，**不会静默换地方**。

### 桌面端有两种形态（v0.11.6）

绿色便携版（目录 + zip，预置空 `data` / `plugins`）与安装版（NSIS，装到当前用户目录，带卸载）。

## 已知不足

- 同步没有进度反馈（一轮通常 <1s；md 放网盘时可能几秒无变化）。
- 所有反馈都走系统通知，被专注助手或通知权限拦掉时界面是静的（`data\logs\` 里有记录）。
- 窗口位置与大小仍记在 `%APPDATA%`（窗口状态插件没有改目录入口），换机器不跟过去。
- 小条因字号变大宽约 3–4 px。
