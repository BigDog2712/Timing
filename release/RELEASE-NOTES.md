# 发布说明 · Timing v0.11.2

2026-11-05。这是一次**巡检版**：不加新功能，只把已有功能的错误修掉。

## 这一版改了什么

三路并行审查（Rust 后端 / 前端状态与副作用 / 双端交互）挖出 45 条，逐条回源码核实后
修掉 20 余处真缺陷，其余 12 条属于「同一件事有两种合理做法」，列入待决等拍板。

### 最要紧的三条

1. **重启后不再把离线时长算进累计。** 以前关电脑时正在计时、开机后 15 秒内没点恢复对话框
   （去倒水、开机自启都算），那段「关着的十几个小时」会被后台折进累计；再选「不计入退出期间」
   也救不回来。现在只要没点对话框，后台一律不动手。
2. **便利贴保存失败不再关窗。** 以前落盘报错时窗口照关，刚写的内容随窗口销毁而消失。
   现在存不上就留着窗口，告诉你可以重试。
3. **进行中的会话不再能被删掉。** 以前删掉后界面显示空闲、却永远起不了新计时，只能改库恢复。

### 桌面端

- 小圆点**能拖了**（上一版漏了，收起后主窗没有任何抓手）；光标变 `grab`，单击仍是展开。
- 跨零点的记录不再显示成 `23:50 - 00:20`，改为「次日 00:20」。
- 事项窗 / 设置窗 / 便利贴窗补上提示条 —— 以前这些窗口的 IPC 失败完全静默。
- 记录面板改归属 / 删除失败会给中文文案，不再冒泡成「界面异常：<后端原始消息>」。
- 事项名含 emoji 时截断不再留下半个「�」。
- 其它窗口调不透明度，不再把主窗临时展开的小条强行收回圆点。

### 手机端

- 便利贴**删除要按两下**（第一下变红，3.5 秒内再点才真删），与桌面同口径。
- 便利贴列表写完 / 改完会立即刷新（以前要切页签）。
- 长按删除的确认条改为**贴着被删那行展开** —— 以前固定在列表顶部，列表一长就看不见。
- 已完成的待办可以长按删掉了。
- 双击「开始」不再弹一条假的「已在计时」报错。
- 通知权限被拒后，去系统设置放开、回来点「申请」能认回来。
- 设置页不再显示「悬浮形态」（手机没有这个形态）。

### 构建

`scripts/android-apk.mjs` 修好了一个会**打错版**的问题：脚本绕过 tauri CLI 直接调 npm 构建，
却漏了 `TAURI_ENV_FAMILY=mobile`，导致打进 APK 的是**桌面版**前端。本版起才是真正的手机版。

## 产物

| 文件 | 说明 |
|---|---|
| `Timing-android-0.11.2-debug-arm64.apk` | 可直接安装（debug 签名，仅 arm64） |
| `Timing-android-0.11.2-release-arm64-unsigned.apk` | release 版，**未签名**，体积 8.7 MB |

release 版没签名所以装不上；它的价值是体积（8.7 MB vs 183 MB，debug 的 `.so` 没 strip）
与「证明 release 链路通」。要能装的正式包得先有 keystore，等你点头。

## 安装

### 安卓

```text
adb install -r Timing-android-0.11.2-debug-arm64.apk
```

或拷到手机直接装（需允许「安装未知来源应用」）。

- 包名 `com.timing.app`，versionCode `11002`，versionName `0.11.2`，minSdk 24。
- **debug 签名**：只能自己装，不能上架、不能给别人长期用。

### Windows

本轮**没有重新打 Windows 安装包**（NSIS 工具链需要联网）。
开发工作区可 `npm run tauri dev` 直接跑；要正式分包需另跑 `npm run tauri build`。

## 已知代价（有意保留）

- 用户始终不点恢复对话框时，累计会停在上一次落盘的值（最多丢 30 秒）——
  「不点就是没决定」，程序不替用户决定。见 `docs/decisions/ADR-041.md`。
- 跨零点的记录仍整段算在开始那天（要改需动今日汇总 / 列表 / md 三处口径，待拍板）。
- 逾期待办仍会自动清理（与「显示逾期」的设计冲突，三种做法都合理，待拍板）。

## 回滚

桌面：装回 v0.11.1 即可，数据结构未变。
安卓：`adb uninstall com.timing.app` 后装旧包。
