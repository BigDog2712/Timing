## 升级步骤（方案 A，推荐）

1. **先退出 Timing**（托盘图标 → 退出，别只关窗口）。
2. 解压 `Timing-0.11.18-portable.zip`。
3. 把解压出来的 `Timing.exe` **单独**复制到 `C:\Software\SmallTools\Timing\`，覆盖同名文件。
4. `data\` 与 `plugins\` 不要碰（zip 里只是占位 README）。
5. 启动，「设置 → 关于」应显示 `0.11.18`。

## 这一版改的四件事

### 1. 本地 / 云端现在是一个开关，在页签最上面

原来那个「启用云端通道」的开关藏在第四块正文里，而**云端没配置过时第四块默认折叠**——等于你看不到它。现在它搬到「数据管理」页签顶部，变成 `只用本地` / `本地 + 云端` 二选一。

选 `只用本地`：云端那一整块变灰但仍显示，配置原样保留，切回来即恢复——不用重填地址和账号。

### 2. 「报红但能同步」的病根找到了，跟 403 判定无关

上一版修的是「坚果云不允许读目录时不再误报」。但你的真实配置是 `mode = 本地目录`，而**「测试连接」按钮原来只出现在 WebDAV 那一栏**——本地目录这条路压根没有自证入口。于是你只能切到 WebDAV 去点，一点就 403 报红，而同步走的其实是本地目录，正常。

现在：本地目录也有「测试连接」，测的是能不能往那个文件夹写一个探针文件再删掉（结果是 `目录可写：<路径>`，全程不联网）；切换载体时会清掉上一次的测试结论，不会再挂着一句跟你现在这条通道无关的红字。

### 3. 托盘：标签说真话，「退出」前先同步

- 托盘那个同步项，标签会跟着**当前真能跑的通道**变：只用本地时是 `Markdown 同步`，本地+云端时是 `云端同步`。云端没填全、或总开关关着时，即使你选过云端，标签也还是 `Markdown 同步`——因为此刻云端根本不会跑，写「云端同步」是骗人。
- 点它时如果云端选了却没填全，会提示 `先在设置里填好云端`。
- **托盘右键「退出」现在会先跑一轮同步再退出**，最多等 3 秒，超时照样退出。等待期间那一项会变成灰色的 `正在同步…`。直接杀进程不做任何处理。

### 4. 两处说明文字改成实话

- 第三块：`日记本：双向，保留你手写的内容。`
- 第四块：`多端一致用：体积小，读得快。`

原来那两句暗示「汇总日记」，但实际做的是**每天一份当时刻的快照**，不是汇总——同一张便利贴会在多天的文件里各存一份，老文件不会回头修正。所以把话改对了。真正的「汇总」要做成另一份单向生成的文件，那是后面的事。

## 装完验一下

1. **页签顶部应该只有一组选择器**（`只用本地` / `本地 + 云端`），第四块里那个旧开关消失了。
2. **切到 `只用本地` → 保存 → 再切回 `本地 + 云端` → 保存**，地址、远端目录、账号应该一个字没丢。
3. **第四块点「测试连接」**（你现在是本地目录模式）→ 应该显示 `目录可写：C:\Users\49801\Nutstore\1\我的坚果云\Timing`，**且界面上不该有任何红字**。这一条只有你能验。
4. **托盘右键 → 退出**：那一项应该立刻变成灰色 `正在同步…`，然后进程在 3 秒内消失。日志 `data\logs\` 里应有 `quit: sync start` 与 `quit: sync done`（或 `timeout`）。**这一条自动化测不到，只能人点**——因为「有没有真的调用那一步」在单元测试里拿不到窗口句柄。

## 已知限制（这版没修，别当成新 bug）

1. **计时那一段两端同时改会互相覆盖。** 你在 md 里给某个事项手写一段计时、同时 PC 端也给同一事项新增一段，md 那段会「认领并覆盖」PC 那段。便利贴和待办不受影响（两条都在）。这版加了 7 条回归测试把这个现状钉住，改行为要单独排期。
2. **待办从 md 里删掉不生效。** 「待办事项」那一节是过滤视图，文件里没有说明不了要删，下一轮导出它又回来。
3. **边改边删会「复活」。** 删掉的那条如果同时出现在正在导入的文件里，会被当成新增重新插入（换了个新 id，统计里记「新增」，没有提示）。
4. **进程重启后第一轮，任何删除都不生效**（合并基线在内存里，不落库）。
5. **第四块状态区在本地目录模式下仍会显示「密码未设置」。** 因为密码那一项的判据无条件读 WebDAV 的凭据。不影响同步，已排进下一版。
6. **云端往期文件只增不减。** 远端现在只有 `2026-11-07.md` 一个，会随时间累积。要做「只留当天」得先定清楚哪些算往期、删失败怎么补、删错了怎么找回——没定之前界面不会写「只留当天」。
