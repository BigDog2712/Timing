# Timing 0.11.23 安装说明（只有手机包）

这一版只做一件：**手机上的备份能导出来了**。

备份列表里每条多了「导出」——点它弹系统「保存到…」，你自己挑位置（下载、网盘同步文件夹都行），
存下来是一个普通的 `.md` 文件。在选择器里按返回就是取消，不算出错。

桌面端只多了一条「仅手机端可用」的桩（电脑上备份本来就在 `data\backups\md\`，卡片上的「打开」
直接能看），**没有任何行为变化**，所以没有新的桌面包，仍用 0.11.20 那两个。

## 手机怎么装

1. 把 apk 拷进手机（数据线 / 网盘都行），点开安装；系统提示「未知来源」就允许一次。
2. **覆盖安装即可**：证书与 0.11.15 / 0.11.21 / 0.11.22 是同一个（本机 `debug.keystore`），不用先卸载。
3. 装完打开 → 设置 → 数据管理 → 备份与恢复：每条右边应该有「导出」（可恢复的那些还有「恢复」）。

## 装完按这个顺序试一遍（只有真机能验）

| # | 怎么做 | 该看到什么 |
|---|---|---|
| 1 | 数据管理 → 备份与恢复 → 任选一条点「导出」 | 弹出系统「保存到…」，文件名的默认值是 `日期-时间.md`（没有 `webdav__` 前缀） |
| 2 | 选「下载」→ 保存 | 那一行下面出现「已保存 2026-11-xx-….md：在你刚选的文件夹里」 |
| 3 | 打开文件管理器 → 下载 | 有那个 `.md`；用任何编辑器打开，内容是那天被覆盖前的日记（含 `#### 事项计时` 等区块） |
| 4 | 再点一次「导出」，这次按返回 | 只出现「已取消，没有写入任何文件」，**没有红字** |
| 5 | 回列表看一眼 | 备份份数**不变**（导出不产生新备份、不动 SQL） |
| 6 | 导出一份电脑上留的底（列表里标「电脑本地」的那条） | 也能导出——导出是副本，不需要落点 |

## 这一版明确没做的

- **不做分享**（发微信 / 邮件）：这版只做「存到自己看得见的地方」，分享是下一个动作；
- **不做批量导出 / 打 zip**：一次一个保存对话框，多份就是连续弹 N 次；
- **不改备份根**：备份仍住在应用私有目录，导出只是「拿出一份副本」；
- **导出的文件不能直接拿来恢复**：恢复要用列表里那条（副本改名换地方之后，程序认不出它的归属）。
