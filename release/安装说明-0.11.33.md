# Timing 安卓 0.11.33 · 安装与自测

> **一句话**：这一版是**版号分家**的第一次出包。功能上跟上一版差别不大，
> 要验的是「手机和电脑的版本号从此各走各的」。

---

## 一、怎么装

| 项 | 值 |
|---|---|
| 文件 | `Timing-android-0.11.33-release-arm64-debugsigned.apk` |
| 大小 | 11,137,060 字节（约 10.6 MB） |
| SHA256 | `fe70dd401b90008ef22a67eb59867b77ef0f13790bbc57c0747c5505acbf8a8c` |
| 架构 | 仅 arm64-v8a（近几年的手机都是） |
| 证书 | 调试证书 `3be0a4c8…a0cf`（与 0.11.32 同一个） |

**覆盖安装即可，数据不丢。**

1. 手机连电脑（或把 apk 传到手机）
2. 点开安装；系统提示「未知来源」就允许这一次
3. 装完直接打开，不需要清数据

> 调试证书的包**不能对外分发**，只自己用。

---

## 二、这版要验什么（就一件事）

**手机上显示的版本号，不再跟着电脑走。**

- 手机：`0.11.33`
- 电脑：`0.11.27`（最后一次出的桌面包）

两个不一样是**对的**，这就是这轮做的事。以前是硬绑在一起，结果手机每发一版都在替电脑预支号，
下次出电脑包会直接从 0.11.27 跳到 0.11.32 —— 中间四个号全不属于它。

### 怎么看到版本号

- 手机：系统「设置 → 应用 → Timing」，或应用详情页的「版本」那一行
- 电脑：`Timing-0.11.27-setup.exe` 装完后，程序里「关于」那一处

### 三条自测

1. **装得上**：覆盖安装成功，打开能正常计时，老记录都在。
2. **号是对的**：手机上显示 `0.11.33`，不是 `0.11.27`、也不是 `0.11.32`。
3. **主路径没坏**：开始 → 暂停 → 继续 → 结束，记录页能看到这一笔。
   （这轮没动功能代码，但底座改了，顺手确认一下更稳。）

## 三、这版**没有**的东西

- **小圆点的新样子（竖条指针、去掉玻璃层）不在这个包里**。
  那条改动是另一个会话在做，提交时间比我打包晚了几十秒，包里的还是上一版的样子。
  下一次出包会带上。
- **日记模板**只有配置链路，界面还没有落地，属于半成品，别当成品用。

---

## 四、出问题怎么回退

装回 `release/archive/Timing-android-0.11.32-release-arm64-debugsigned.apk` 即可
（同证书，可以直接覆盖回去）。数据不会因为回退丢。
