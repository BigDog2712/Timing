# Timing 桌面 0.12.10 · 安装与自测

> **一句话**：悬浮框左侧小圆环右键恢复「结束并保存」；今日时间线卡下线「常用事项」组。
> 上一版桌面出包是 0.12.7。

---

## 一、怎么装

| 项 | 值 |
|---|---|
| 安装包 | `Timing-0.12.10-setup.exe`（约 8 MB，NSIS） |
| 便携版 | `Timing-0.12.10-portable.zip`（解压即用，数据在 exe 同级 `data\`） |
| SHA256 | 见 `SHA256SUMS-0.12.10.txt` |
| 构建身份 | `BUILD-INFO-0.12.10.txt`（提交号与工作树状态，与包一一对应） |

覆盖安装即可。老数据自动迁移（只复制不移动，原目录不动）；已有布局不会被改写。

## 二、这版有什么

### 1. 右键圆环 = 结束并保存（恢复）

计时中 / 暂停态右键悬浮框左侧小圆环直接结束并保存，结束弹撤销条（点错可悔）；
低于最短记录时长只提示不记录。空闲态右键不绑。想多看一眼再结束仍可走
计时小面板（点计时数字 / 圆环上按 Enter，面板内按钮带两步确认）。

### 2. 今日时间线卡删除「常用事项」显示

时间线下区只剩今天的记录（进行中 / 已暂停 / 已完成）；「新建事项」「编辑事项」
两颗入口不变。一键开始常用事项去「事项管理」卡。

### 3. 自测清单

1. 开始计时（点圆环）→ 右键圆环 → 计时结束、出现撤销条、点撤销恢复计时；
2. 暂停态右键圆环 → 同样结束；
3. 空闲态右键圆环 → 无动作（预期）；
4. 分析窗「今日时间线」卡 → 时间线下没有「常用事项」分组；
5. 「事项管理」卡 → 常用事项组仍在，点行起停正常。
