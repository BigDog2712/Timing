# Timing 0.11.20 安装说明

产物（都在 `D:\101-Workshop\261108-Timing\release\`）：

| 文件 | 体积 | 用途 |
|---|---|---|
| `Timing-0.11.20-portable.zip` | ~3.7 MB | **推荐**。解压后只覆盖 `Timing.exe`，数据原地不动 |
| `Timing-0.11.20-setup.exe` | ~4.7 MB | NSIS 安装包（装到 `%LOCALAPPDATA%\Programs\Timing`） |
| `SHA256SUMS-0.11.20.txt` | — | 两个文件的校验和 |
| `BUILD-INFO-0.11.20.txt` | — | 这份包是哪个 commit、什么时间编的（便携 zip 里也有一份） |

> 体积与 sha256 待出包后回填。

这一版**不加功能**，是清障轮：修两条偶发红的自动化测试、包里带「出生证」、删 7 条孤儿样式、
文档补齐（`CHANGELOG.md` 补齐 0.11.17–0.11.20，`RELEASE-NOTES.md` 重写）。
**没有数据库迁移**（仍到 `0006`），覆盖 exe 不会动你的数据。手机端零改动，安卓包仍用 0.11.15 那个。

---

## 升级步骤（方案 A，推荐）

1. **先退出 Timing**（托盘图标 → 退出，别只关窗口）。
2. 解压 `Timing-0.11.20-portable.zip`。
3. 把解压出来的 `Timing.exe` **单独**复制到 `C:\Software\SmallTools\Timing\`，覆盖同名文件。
4. `data\` 与 `plugins\` 不要碰（zip 里只是占位 README）。
5. 启动，「设置 → 关于」应显示 `0.11.20`。

**方案 B（安装包）**：跑 `Timing-0.11.20-setup.exe`。注意它装到 `%LOCALAPPDATA%\Programs\Timing\`，
那里是**空的 data 目录**，不会自动读到你原来的数据——要沿用旧数据得手工把 `data\` 搬过去。

## 出包后待人工验证

沿用 0.11.19 遗留的三条（都还欠着）：

1. **中文安装向导**：跑一次 `Timing-0.11.20-setup.exe`，看许可协议 / 快捷方式 / 卸载界面是否全中文。
2. **托盘「退出」先同步**：改一笔数据，立刻托盘右键退出，看是否出现灰字「正在同步…」、数据有没有同步。
3. **真坚果云真删端到端**：远端只剩今天那一份、`md-cloud-purge.log` 逐条可追、
   `data\backups\md\` 有 `folder__` / `webdav__` 前缀留底。**这是真删功能唯一没被自动化覆盖的终局验证。**
