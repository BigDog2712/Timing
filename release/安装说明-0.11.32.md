# Timing 0.11.32 安装说明

> 这一版**只有手机包**（桌面零代码改动，仍用 0.11.27 的便携包 / 安装包）。
> 覆盖安装即可，不用卸载；调试证书签名，与上一版同签。

## 你报的四条，逐条对照

| # | 你说 | 这一版 |
|---|---|---|
| 1 | 点击便利贴可弹出查看完整便利贴 | 点一行 → 弹出**只读全文**（整段铺开、可上下滚，不再封两行），底部「编辑」再进编辑页 |
| 2 | 悬浮窗形态点暂停 / 开始未成功；长按应跳计时界面 | 点按**真的能暂停 / 开始**（换掉了整条投递路）；长按回来落在**计时页**，不再是上次那个 Tab |
| 3 | 常用事项就这样，但把"与电脑版一致"的描述删掉 | 提示改成「行尾的图钉 = 设为常用」 |
| 4 | 支持未命名事件直接计时，结束时让用户填名称 | 悬浮条单击（待机时）= 直接开始一笔**未命名**计时；结束后面板问「这段时间在做什么？」，填名字或点一个常用项即可 |

## 第 2 条到底哪坏了（值得你知道）

不是手势的问题——圆点展开那半截一直是好的，坏在**"按了之后把动作交给界面"这一步**。
上一版用的是框架的插件事件注册，那一步内部走反射，打包压缩后可能注册不上；
注册不上时前端把那句错误**吞掉了**，原生那边也只拿到一个 false，于是：

- 你看到的：圆点展开成条 → 计时一动不动；
- 两边的日志：一个字都没有。

现在改成原生**直接调界面里的一个函数**（不再有注册这回事），并且加了一道自检：
按下去 1.2 秒后如果标记还在、画面也没变，就把原因写进**通知副标题**
（"这一按没生效：界面没接上（回到 App 会自动补做）"）——至少你以后能看见它在说什么。

顺带修了一处也会造成"点了没反应"的地方：**切状态前先向后台要一次真值**。
App 在后台待久了，界面里记的还是旧状态，拿旧状态去"暂停"会发出一条必然被拒的命令。

## 关键口径（免得你以为是 bug）

- **便利贴点开是"看"，不是"改"**。想改就点底部「编辑」。长按仍然是删除（会先问一次）。
- **悬浮条点按在"待机"时记的是未命名的一笔**（不是上次那件事）：悬浮条上没有选事项的位置，
  替你猜一件事反而会记错名字。结束时会问你要名字。
- **命名面板里点一个胶囊 = 直接记到那一项**，不用再打字；同名的事项会被**复用**，
  不会因为多敲了个空格就建出第二条。
- **「先不命名」是允许的**：这一段继续放在「未归类」里，随时能在记录页改归属。
- **长按落点是计时页**，并且会顺手关掉当时盖着的面板。
- 太短的计时（不足「最短记录时长」）结束时不问名字——那段本来就没入库。

## 自测五步

1. **看便利贴**：便利贴页点一张内容很长的 → 应该弹出整段（能滚），不是输入框。
   → 底部「编辑」进编辑器，改完「完成」返回。
2. **悬浮条暂停**：计时页开始计时 → 回到桌面 → 点悬浮条 → 回计时页看是不是「已暂停」；
   再点一下应该「继续」。
3. **长按落点**：先停在"记录"页，长按悬浮条 → 回来应该在**计时**页（不是记录页）。
4. **未命名计时**：待机时点悬浮条 → 计时页显示「未归类」并开始走秒 → 结束 →
   面板问「这段时间在做什么？」→ 输入一个名字 → 记录页里这条挂到新事项上。
5. **不命名**：同样的流程点「先不命名」→ 这段留在「未归类」，不报错、不弹红字。

## 已知边界

- 命名面板弹出时会盖住那 3 秒的撤销条：想撤销得先关面板（3 秒内）。
- 悬浮条点按的**首次**使用：如果 App 的界面已经被系统回收，这一按只会留下标记
  （通知副标题会说），回到 App 时自动补做一次。
- 长按能不能拉起 App，仍取决于系统「后台弹出界面」权限；被拦时原因会写进通知副标题。
- iOS 未打包：本仓只做安卓本地打包。

## 安装

1. 把 `Timing-android-0.11.32-release-arm64-debugsigned.apk` 拷到手机（微信文件传输助手 /
   数据线都行）。
2. 点开安装；提示「未知来源」就允许一次。覆盖安装即可，数据不丢。
3. 校验（可选）：`sha256sum` 应为
   `a6497e05c40b66d3d913e2d0e3119b819267b8cb6370391181dfe3cb0573ef3d`。
