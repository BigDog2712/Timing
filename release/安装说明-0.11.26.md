# Timing 0.11.26 安装说明

这一版修一个真故障：**手机同步报「建不了云端落点目录 permission denied（os error 13）」，
日记传得上去、却存不回本地。**

原因是路径里那根反斜杠：出厂落点是 `%APP_DIR%\md-webdav`，`\` 在 Windows 上是分隔符，
在手机上只是一个普通字符。于是手机把 `com.timing.app\md-webdav` 当成**一整个名字**，
要把它建在 `/data/user/0` 下面——那是系统目录，应用不能写，直接拒绝。
「测试连接」只碰网络、一个本地文件夹都不建，所以它一直是绿的：**连得上、存不进来**，
两件事同时成立，不是配置填错了。

修法：落点路径按平台换分隔符（**电脑上一位都没变**），错误文案补上完整路径，
每轮同步再记一行落点日志。

## 手机（Android，arm64）

`Timing-android-0.11.26-release-arm64-debugsigned.apk`（11.1 MB）

- 与本机之前几个包**同一张调试证书**（0.11.15 / 21 / 22 / 23 / 25 那几张的同一条），
  **覆盖安装不用先卸载**；
- 装完进「设置 → 数据管理」，先点一次「立即同步」。

### 自测四步（做完这四步，这个故障就算真的关掉了）

| # | 做什么 | 该看到 |
|---|---|---|
| 1 | 直接点「立即同步」 | **不出红字**（上一版这里必然出「建不了云端落点目录 …」） |
| 2 | 看同步结果那一段 | 导出 / 导入条数有数，或至少「今天没有变化」 |
| 3 | 去坚果云（或你的 WebDAV）看当天的 `yyyy-mm-dd.md` | 在，且内容与手机上今天的一致 |
| 4 | 手机放后台等 5 分钟（智能档），再回来 | 没有新增红字；通知栏里 Timing 还在 |

哪一步不对，把屏幕上那句话发我——现在错误里会带**完整路径**，一眼能看出是哪个目录。

> 手机上的落点文件在 `/data/user/0/com.timing.app/md-webdav/`，那是应用私有沙箱，
> **文件管理器进不去**（Android 的设计）。要看内容就去云端看，或者从备份列表「导出」拿一份。

## 电脑（Windows 双形态）

| 文件 | 体积 | 用途 |
|---|---|---|
| `Timing-0.11.26-portable.zip` | 3.7 MB | **推荐**。解压后只覆盖 `Timing.exe`，数据原地不动 |
| `Timing-0.11.26-setup.exe` | 4.8 MB | NSIS 安装包（装到 `%LOCALAPPDATA%\Programs\Timing`，数据不跟着走） |
| `SHA256SUMS-0.11.26.txt` | — | 三个产物的校验和 |
| `BUILD-INFO-0.11.26.txt` | — | 这份包是哪个 commit、什么时间编的 |

桌面本来就没事（`\` 在 Windows 上是分隔符），但改的是两端共用的一小段代码，
不跟着换会留两套行为，所以这版桌面包也重出了。桌面唯一的可见差别是：
建不了落点目录时，红字里会带**完整路径**。

## 仍然不做

- 「导入自签 CA」——根证书仍是程序内置的一份公网根，见 `待决事项`。
- 把手机落点搬到共享存储 / 让文件管理器看得见：那是另一件事（要做也是走导出）。
- 正式签名：手机包仍是调试证书，自用够；给别人装需要换正式证书（要先卸载）。
