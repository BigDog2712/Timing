# Timing 桌面 0.12.6 · 安装与自测

> **一句话**：待办并进「今日时间线」卡、另起一张「事项管理」卡，工具类应用不再拉歪统计，
> AI 打标签开始看"这个软件到底干什么"，标签能拖着换分类了。
> 上一版桌面出包是 0.12.1；0.12.2–0.12.5 赋号未出包，改动全部并入本版。

---

## 一、怎么装

| 项 | 值 |
|---|---|
| 安装包 | `Timing-0.12.6-setup.exe`（约 8.0 MB，NSIS） |
| 便携版 | `Timing-0.12.6-portable.zip`（解压即用，数据在 exe 同级 `data\`） |
| SHA256 | 见 `SHA256SUMS-0.12.6.txt` |
| 构建身份 | `BUILD-INFO-0.12.6.txt`（commit `3cc940f`，工作树 clean） |

覆盖安装即可。老数据自动迁移（只复制不移动，原目录不动）；**布局也是自动迁移**：
原来那张「待办事项」变成「事项管理」卡、原来那张「今日时间线」留在原位置和原大小，
你给卡改过的名字不会被抹掉。

## 二、这版有什么

### 1. 两张卡，各管一件事

- **今日时间线**：上半区待办（时间胶囊 / 提醒铃铛 / 勾选 / 编辑 / 3 秒撤销一样不少），
  下半区今天的计时记录，中间一条浅横线。卡上只剩「新建待办」一个入口。
- **事项管理**（新）：常用（置顶）/ 历史两组；新增 / 编辑 / 事项管理；
  **点一下行就开始计这一件**，再点一下结束；AI 一键分类；已绑定应用的标记。
  这张卡管事项本身，**不设时间** —— 时间在你点下去那一刻才产生。

### 2. 标签拖着换分类

数据页 → 标签管理：把一行拖到另一行上 → 成为它的子标签（整棵子树跟着走）；
拖到列表上方的虚线框 → 回到一级。拖不成会当场说清理由（拖进自己子树会绕成环、
超过 4 级、撞上同名标签），**同名不会替你合并** —— 合并了就再也分不开。

### 3. 工具标签不计数

下载器 / 终端 / 截图 / 系统维护打上「工具」标签后，时长不再算进总时长与分类分布；
排行里还看得到，标「工具」、占比 0%。一天只用了工具类应用时，环心会说
「今天只有工具类应用（时长），不计入统计」，而不是"今天还没有记录"。

### 4. AI 打标签按用途判断

Chrome → 工作 / 生活 / 学习 / 娱乐；游戏只给「娱乐」；Obsidian → 生活 / 学习 / 娱乐；
IDM / Windows Terminal / Snipaste → 工具。事项侧自动建两级标签（吃饭 → `生活/吃饭`），
并优先复用你已有的标签，同类的事下次还归到同一处。

## 三、自测清单（五分钟）

1. 主界面：看得到「今日时间线」与「事项管理」两张卡（不是合并成一张）。
2. 事项管理卡点一行 → 行上出现正在计时的标记、时间线卡下区多出一条「进行中」；
   再点一下 → 停止。
3. 时间线卡上区「新建待办」→ 填名 + 选 2 分钟后的时间 + 勾提醒 → 行上有铃铛与时间胶囊。
4. 数据页标签管理：把 `学习/考公` 拖到 `工作` 上 → 变成 `工作/考公`，子标签一起走；
   再拖到上方虚线框 → 回到一级。
5. 给某个下载器打「工具」标签 → 计时分布卡的总计与分类分布里它消失，应用排行里它还在、
   标着「工具」、占比 0%。
6. 老数据还在：升级前的计时记录、便利贴、待办都原样出现；改过名字的卡名字还在。

## 四、已知边界

- **趋势图与热力图这一版还没剔除工具时长**：它们取的是后端逐桶并集，无法逐应用扣除，
  与总量之间会有差额，属既定取舍。
- 事项管理卡的「撤销本次分类」是"写回空数组"，不是精确回滚 —— 应用之后到你点撤销之间
  手工加的标签也会被清掉（窗口很短）。
- 不足最短记录时长（默认 30 s）的段落地时不会入库，药丸上会提示；事项管理卡上那句
  只说「已停止」，不承诺已入库。
- 点「大」档会让卡片压到邻卡（自由摆位本来就允许重叠，整理是退路）。
- 手机端本版不动：0.12.13（12013）。
