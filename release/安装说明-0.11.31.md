# Timing 0.11.31 安装说明

> 这一版**只有手机包**（桌面零代码改动，仍用 0.11.27 的便携包 / 安装包）。
> 覆盖安装即可，不用卸载；调试证书签名，与上一版同签。

## 你要的三条，逐条对照

| # | 你说 | 这一版 |
|---|---|---|
| 3 | 换事项菜单应唤起像电脑端的快捷菜单，显示近期事项与常用事项，并有相应设置功能 | 面板分三段：**常用**（你自己钉的）/ **最近用过** / **其他事项**；每行右边一个图钉，点一下就是「设为常用」 |
| 5 | 事项页记录改为已完成待办、同事项多段按事项合并、不与计时重复；待办支持预计时间与提醒、可选几天后 | 第三段改成**已完成待办**（多段合并成一行 + ×N 段 + 合计时长，并标「已完成 / 未勾选」）；待办输入框右边多一个日历按钮 = **排时间**（今天 / 明天 / 3 天后 / 7 天后 + 几点） |

## 关键口径（免得你以为是 bug）

- **常用是「谁钉的谁在前」**，没有任何算法排序。手机和电脑认的是同一个字段：
  你在手机上钉的，电脑上的常用列表立刻也有。
- **「近七天」是 7 个自然日（含今天），不是最近 168 小时。**「本月」是 1 号 00:00 起到今天。
- **周一当天选「本周」只有今天**，这是口径：周一是第一天。
- **事项页计了时但没打勾的仍然显示**，标「未勾选」——不显示的话你会以为数据丢了。
  这一页**不再有任何「开始计时」按钮**（你说的「不与计时界面功能重复」）：计时去计时页。
- **待办排时间用的是「开启时间」**（电脑版那张卡里叫开启时间），后端会在开始前
  15 分钟、5 分钟各提醒一次，到点若你正闲会自动开始计时。手机端这一版**补了系统通知**
  ——之前待办提醒在手机上从来没响过（事件发出去没人接）。

## 自测五步

1. **钉常用**：计时页 →「换事项」→ 找一个常用的事 → 点它右边的图钉。
   会提示「已把 X 设为常用」，并且它立刻移到顶上的「常用」组。再点一下取消。
2. **看合并**：今天对同一个事项计了两段（中间换走过）
   → 事项页「已完成待办」里应该只有一行，写着「×2 段」。
3. **排个 3 天后的待办**：事项页输入内容 → 点右边日历图标 → 点「3 天后」→ 选时间
   → 「就这个时间」。第一次会弹通知授权，给个「允许」。
4. **翻往期**：记录页顶部往右划 → 点「本月」看总数；点「往日」选昨天，总计和明细都应变。
5. **确认没有计时入口**：事项页那一段里点一行 = 事项编辑（改名 / 归档 / 删除），
   行尾不再有「开始」按钮。

## 已知边界

- 排时间**不能选过去的时刻**（选了过去会红字提示）：后端会把过期待办静默标成已处理，
  你会觉得「加了但没响」。要补昨天的账，请在电脑上补。
- 手机端不暴露「截止时间」：电脑版那张卡有开始 / 截止两个时间，手机上并排两个日期控件
  分不清，先只给「哪天几点」。逾期变红仍然只在电脑端。
- 通知被系统拒了的话，到点不会有横幅（应用内也不会有）——去
  设置 → 通知权限，那里会显示「已拒绝」。

## 电脑（Windows）

与 0.11.30 相同，仍是 **0.11.27** 的产物（本版没动桌面代码）：

- `Timing-0.11.27-portable.zip`：解压即用，数据跟着 `data\` 走；
- `Timing-0.11.27-setup.exe`：装到 `%LOCALAPPDATA%\Programs\Timing`。
